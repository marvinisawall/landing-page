⚡ MSN Africa Landing Page

A landing page project built while working through The Odin Project's curriculum, using HTML & CSS fundamentals (Flexbox and layout structure).

🎯 Inspiration

Instead of a generic placeholder landing page, I wanted to build something with a story behind it. This project is inspired by FC Barcelona's legendary MSN trio  Messi, Suárez, and Neymar ,one of the most devastating attacking lines in football history.

The twist: this page imagines a future MSN born in Africa, a new generation of attacking talent from the continent that could one day recreate that same magic on the world stage. Part tribute, part vision board.

🛠️ Built With
HTML5
CSS3 (Flexbox)

📖 What I Practiced
Structuring a full landing page (header, hero, info section, testimonial, CTA, footer)
Working with color contrast and typography hierarchy
Building reusable, consistent components (buttons, cards)

🚧 Known Limitations
Not yet responsive, currently designed for desktop view only. Mobile responsiveness is a planned next step.
